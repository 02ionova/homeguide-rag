# Local source manuals

Download these original PDFs and save them under the readable local filenames below. Only the filenames have changed; PDF contents and original SHA-256 hashes are preserved. The official download URLs still use Bosch's original document numbers. The app only serves registered documents in `documents.json`.

- [Bosch-WAV28EH3GB-Washing-Machine.pdf — Bosch WAV28EH3GB washing machine](https://media3.bosch-home.com/Documents/9001599859_B.pdf)
- [Bosch-SMS8ZDI86M-Dishwasher.pdf — Bosch SMS8ZDI86M dishwasher](https://media3.bosch-home.com/Documents/9001722657_D.pdf)
- [Bosch-TIS-3.3-Coffee-Machine.pdf — Bosch TIS 3.3. coffee-machine family](https://media3.bosch-home.com/Documents/8001036206_B.pdf)

These manufacturer-owned manuals were provided locally. Permission to redistribute has not been established; private GitHub visibility is not permission. PDFs and extracted text are excluded from Git. Including 3–5 PDFs in a university submission remains unresolved until permission is established. Download for your own authorized use under the manufacturer's terms, or substitute documents you may redistribute and update the manifest. Initial SHA-256 values and original page counts are recorded in the manifest; originals must be preserved.
